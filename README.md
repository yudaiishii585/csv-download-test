# ひなた製菓 販売管理システム（研修用ダミーサイト）

ブラウザ操作の自動化を練習するための、**架空の社内システム**です。
ログインして条件を選び、売上データをCSVでダウンロードできます。

## わざと不便に作ってあります

このサイトは「自動化の練習台」なので、**手作業だと面倒**になるよう作ってあります。

- **対象月とカテゴリは1つずつしか指定できません。** まとめて出力する機能がありません
- **CSVダウンロードは検索した後でないと押せません**
- **条件を変えるとダウンロードボタンが押せない状態に戻ります**
- 検索とダウンロードに毎回1秒弱かかります

12か月 × 5カテゴリ = **最大60回**の繰り返しになります。
世の中の業務システムにありがちな仕様です。

## データについて

- 期間：FY2025（2025年4月〜2026年3月）の12か月
- カテゴリ：焼き菓子 / 生菓子 / ギフト / 季節限定 / その他
- 店舗：本店 / 駅前店 / 催事 / オンライン
- 1回の出力：36行（3日分 × 4店舗 × 3商品）。店舗を指定すると9行
- CSVは Excel でそのまま開けます（UTF-8 BOM付き）

**乱数を使っていません。** 条件から計算で数字を出しているので、
何度検索しても同じ値が出ます。答え合わせができます。

仕込んである傾向：

| 傾向 | 内容 |
|---|---|
| ギフトが12月に跳ねる | 通常月の3倍 |
| 季節限定は夏と12月だけ伸びる | それ以外の月は0.6倍 |
| 生菓子は夏に落ちる | 6〜8月が0.7倍 |
| バターサンドが2026年1月から値上げ | 1600円 → 1800円 |

最後の値上げは、1〜3月のCSVを取らないと気づけません。

## 中身

静的ファイルだけで動きます。サーバーは不要です。

```
index.html   ログイン画面
app.html     売上データ抽出画面
data.js      ダミーデータの生成とCSV組み立て
style.css
```

ローカルで動かす場合は、このフォルダを適当な静的サーバーで配信してください。

```bash
npx serve .
```
